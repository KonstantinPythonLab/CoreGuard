# Pi ecosystem partner outreach — prepared prospects (English · العربية)

> Pi Network ecosystem partner outreach is a prepared prospect list, not signed partnerships. The partners below are segments and example types to approach for integration, not names that have signed anything with CoreGuard.

## Segments

1. **Pi wallet providers.** Wallets that hold Pi and sign Pi transactions. Integration: Pi Wallet pre-sign verification overlay — ALLOW / DENY / HOLD with a verifiable receipt before the wallet signs.
2. **Pi DApp builders.** DApps on Pi Browser that process Pi transactions. Integration: Pi DApp SDK — each DApp transaction runs through CoreGuard and shows the user a receipt before sign-off.
3. **Pi agent platforms.** AI agents that act on Pi Network on behalf of users. Integration: agent execution verification — every agent action verified before settlement, so the user sees what the agent did and why.
4. **Pi ecosystem services.** Oracles, data services, escrow services, settlement services. Integration: execution attestation service — issue a verifiable attestation for the transactions they process.
5. **Pi community apps.** Community-built apps on Pi Network. Integration: light CoreGuard verification for transaction integrity, so community apps can show users a receipt.
6. **Pi audit and compliance services.** Auditors and compliance services. Integration: execution-proof reporting — auditors re-derive Pi transactions from the receipt and the on-chain anchor.

## Approach

- Outreach starts with the summit presence (showcase, hackathon, one-pager).
- Each segment gets a tailored integration point (SDK, overlay, attestation service, audit reporting).
- Conversations stay evidence-first: the integration model is shown, not promised.
- No signed partnerships are claimed until a named event with evidence exists.
- No revenue, customers, audits or third-party endorsements are claimed for Pi Network until evidence exists.

## What is not claimed

- No Pi ecosystem partner is signed yet.
- No Pi Network funding, incubation or hackathon prize is confirmed yet.
- No revenue, customers, audits or third-party endorsements are claimed for Pi Network until evidence exists.
