# Pi Network incubation proposal (English · العربية)

> This is a prepared incubation proposal for Pi Network ecosystem integration.
> It is a proposal, not an award. No incubation is claimed until a named event
> with evidence exists. VERIFIED ≠ SAFE.

## Goal

CoreGuard wants to incubate the execution-truth layer for Pi Network:
deterministic, replayable proof of what was authorised versus what executed,
fail-closed, before the transaction settles — the same pattern already proven
on Core DAO and Stellar.

This document is an incubation proposal template for that work. It is bilingual
(English · العربية) and claim-disciplined.

## What the incubation delivers

1. **Pi Browser verification overlay (prototype → production).** Start with a
   prototype overlay that runs a Pi DApp transaction through CoreGuard and shows
   the user a receipt summary. Move to production once Pi mainnet is live.
2. **Pi Wallet pre-sign check (prototype → production).** Add a pre-sign
   verification step to Pi Wallet, so the wallet never signs a transaction it
   cannot explain.
3. **Pi DApp SDK (reused from Core and Stellar).** Pi DApps call the same
   verifier. The SDK is reused, not rewritten.
4. **Pi mainnet commitment anchor (prepared → live).** Once Pi mainnet is live,
   deploy the anchor and produce the first execution proof.
5. **Pi ecosystem attestation service.** Pi ecosystem services issue execution
   attestations for their transactions.
6. **Cross-network anchor with Core + Stellar.** Same verifier and receipt
   format across all three networks.

## Incubation phases

1. **Phase 0 — preparation (now → summit).** Materials ready. No claim of
   incubation yet.
2. **Phase 1 — summit showcase (Nov 17–19, 2026).** CoreGuard presented.
   Hackathon participation. Ecosystem partner outreach. No signed partnerships
   claimed.
3. **Phase 2 — pilot (post-summit, post-mainnet).** Once Pi mainnet is live,
   anchor deployed, pilots ship.
4. **Phase 3 — adoption scale.** Attestation service ships, adoption grows.

## What is not claimed

- No incubation is claimed yet. This is a proposal, not an award.
- No Pi Network incubation programme is confirmed.
- No signed partnerships are claimed for Pi Network.
- No revenue, customers, audits or third-party endorsements are claimed for
  Pi Network until evidence exists.
