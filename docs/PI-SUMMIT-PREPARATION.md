The summit is the right moment for CoreGuard to present itself as the execution-truth layer for Pi Network: the same pattern already proven on Core DAO and Stellar, prepared for Pi mainnet and ready to ship on Pi Browser and Pi DApps.

## Summit presence goals

1. **Showcase the execution-truth layer.** Present CoreGuard as the missing layer for Pi Network: a deterministic, replayable proof of what was authorised versus what executed, fail-closed, before the transaction settles.
2. **Show the cross-network pattern.** Demonstrate that the same verifier and receipt format run on Core DAO (chain 1116), Stellar (Soroban anchor) and Pi (prepared for mainnet). That is the differentiator.
3. **Run a hackathon project.** Enter the Pi Next hackathon with a Pi DApp or Pi Wallet demo that integrates CoreGuard verification and shows a real execution receipt on a test or staging environment.
4. **Open ecosystem partner outreach.** Identify Pi wallet providers, Pi DApp builders, Pi agent platforms and Pi ecosystem services as integration prospects.
5. **Prepare a milestone-gated funding request.** Prepare a funding request template in case Pi Network opens an ecosystem grant or incubation programme similar to the Stellar Community Fund model.

## Summit materials (prepared)

1. **Pi Ecosystem Summit one-pager (EN/AR).** A two-language one-pager that presents CoreGuard as the execution-truth layer for Pi Network: the problem, the pattern, the cross-network proof, the integration points and the honest status.
